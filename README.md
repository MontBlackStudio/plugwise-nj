# PlugWise NJ

Conversion-first SEO lead-generation site for EV charger installation quotes in New Jersey.

PlugWise NJ helps homeowners request Level 2 / Tesla Wall Connector installation quotes from photos and route those quote requests to independent licensed electricians or service providers where available. The site is intentionally positioned as a quote coordination platform, not as a fake electrical contractor.

---

## Current route inventory

Built SEO pages:

- `/` — homepage / broad Level 2 quote funnel

## Lead capture behavior

The quote form posts JSON to `/api/quote`.

Development:

- If `QUOTE_WEBHOOK_URL` is not set, valid leads are appended to local `.data/quote-leads.jsonl`.
- `.data/` is ignored and is only a local development convenience.

Production:

- `QUOTE_WEBHOOK_URL` must be configured.
- If it is missing in production, the API fails safely instead of silently accepting leads that go nowhere.
- Webhook delivery uses JSON, HTTPS validation, timeout handling, and non-2xx failure handling.
- Server logs intentionally avoid dumping full PII payloads.

Example env value:

```bash
QUOTE_WEBHOOK_URL=[REDACTED]
```

Do not commit real credentials or webhook URLs.

## SEO / compliance posture

Current posture:

- No fake Tesla authorization/certification claims.
- No fake utility affiliation claims.
- No fake reviews or rating claims.
- Rebate pages should cite/reflect official utility status and avoid invented amounts.
- Electrical work is described as performed by independent licensed electricians/contractors where available.
- The site should use FAQPage/BreadcrumbList/Organization/Service schema conservatively; avoid fake LocalBusiness/Product/Offer/review schema unless the business facts justify it.

Known immediate roadmap gaps:

- Add `/privacy` and `/terms` before scaling traffic.
- Clean old trust copy such as “never shared” language.
- Align old homepage/FAQ cost language with the dedicated cost page.
- Remove placeholder `href="#"` links.

See the current SEO audit and roadmap:

`docs/plans/2026-06-07-plugwise-seo-audit-roadmap.md`
